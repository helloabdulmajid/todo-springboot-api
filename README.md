# Todo Spring Boot API

Backend REST API for a full-stack Todo application built using Spring Boot, Spring Data JPA, Hibernate, and MySQL.

## Features

- REST APIs
- CRUD Operations
- MySQL Database Integration
- Spring Data JPA
- Hibernate ORM

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL

## Run Project

./mvnw spring-boot:run
